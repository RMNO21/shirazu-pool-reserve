# Shiraz Pool Auto-Reserve

High-speed auto-reservation Chrome extension for Shiraz University sports/pool booking system (`sups.shirazu.ac.ir`).

Developed by **Raman Tondro** ([@RMNO21](https://github.com/RMNO21)).

---

## Features
- **Fast Monitoring**: Live cache-busted checks every second directly against the server.
- **Sniper Mode**: Instant continuous booking attempts for competitive registration rushes.
- **Interactive UI**: Target any slot via dropdown or direct cell clicking on the schedule table.
- **Audio & Desktop Alerts**: Plays a chime and sends a notification immediately upon confirmation.

---

## Installation

1. Clone or download this repository:
   ```bash
   git clone https://github.com/RMNO21/shirazu-pool-reserve.git
   ```
2. Open Chrome and go to `chrome://extensions/`.
3. Enable **Developer mode** in the top right.
4. Click **Load unpacked** and select this directory.
5. Navigate to the Shiraz University reservation page (`/SfxWeb/Emp/SfeReserve.aspx`).
